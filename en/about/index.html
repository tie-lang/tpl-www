About

The license

The Tie Public License (TPL) is a permissive, attribution-based open source license published as a generic, reusable text: any individual or legal entity may adopt it for any kind of work, without any affiliation to or endorsement by the TIE-LANG organization. It is general-purpose and field-of-use neutral, and it is written to answer the questions newer licenses leave silent — AI training, works built with the material, hosted services, third-party assets and brand protection.

Who maintains it

TPL is published and maintained by the TIE-LANG organization, the organization behind the tie programming language. The canonical, always-current license text is tpl.txt in the tie-lang/TPL repository.

Versioning policy

  • The current version is TPL 2.2 (published 2026-09-25). New adoptions should use it.
  • On every version bump, the repository keeps the authoritative tpl.txt and a frozen, byte-identical copy named after the version (2.1, 2.0, …), so historical texts remain exactly retrievable.
  • Works already distributed under an earlier version stay governed by that version. Archived texts: 2.1, 2.0.

About this site

This site is intentionally minimal — plain hand-written HTML and a single stylesheet, in the spirit of llvm.org: no frameworks, no build system, no client-side JavaScript, no trackers. Every license page is generated mechanically from the TPL repository's text files, so what you read here is byte-faithful to the canonical text; version bumps regenerate the pages rather than hand-editing them. The server negotiates the initial language from the Accept-Language header; the switcher in the navigation goes directly to the other language.

Adoption

TPL 2.2 is the standard license across the TIE ecosystem's repositories. You do not need permission to use it: see Using TPL for the notice formats, and the FAQ for common questions.
