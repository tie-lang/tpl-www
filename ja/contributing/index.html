Tie Public License への貢献

TPL は TIE-LANG 組織が tie-lang/TPL リポジトリで維持しています。本ページでは貢献の方法を説明します。

貢献できること

  • 正誤表と表現の修正。ライセンス本文中の誤字、壊れた相互参照、不明瞭な表現。
  • 翻訳。新しい言語版、または既存の翻訳への訂正。
  • 解釈ノート。ある条項がどのように適用されるかの説明（FAQ 用）。
  • ウェブサイト。本サイト（tpl-www）の修正と改善。

ライセンス本文はどう変わるか

ライセンス本文は版管理され、凍結されています。公開された各版は不変です。TPL 2.3 が公開された後、その本文は変わりません。訂正と改善は次の版（例えば TPL 2.4）に入り、以前の版の下で既に配布された著作物は引き続きその版に服します（第 14.3 条）。

これは意図的なものです。採用者は、自分が承諾した条件が後から書き換えられないことを知る必要があります。

変更を提案する

  • 問題を説明する issue を立て、可能であれば提案する文言も示してください。文言だけでなく、採用者への影響を説明してください。
  • 具体的な草案がある場合は、drafts ディレクトリに対して pull request を立ててください。草案はどの版を公開する前にも検討されます。
  • 条項を明確にするのではなく法的効果を変える変更は、正誤表ではなく新しい版として扱われます。

翻訳を提供する

翻訳は他の言語版と並ぶファイルとして提案します。公式翻訳として指定されるには、次を満たす必要があります：

  • 英語本文の構造に従うこと — 節と条項の番号を同一にし、相互参照がどの言語でも解決できるようにする；
  • 節見出しのアンカー形式を保ち、付録の通知テンプレートをそのまま使用できるようにする；
  • 対象言語に通じた者による法的正確性の校閲を受けること。翻訳は指定されると許諾者の承認を帯びるため、作業訳よりも高い基準が求められます。

指定は OFFICIAL-TRANSLATIONS.md に記録されます。ライセンスの新版には新たな指定が必要です。

本文自体への貢献

あなたが別段の申立てをしない限り、ライセンス本文への収録のために提出するものは、ライセンス自体の条件の下で提供され（第 7.1 条）、あなたは提出する権利を有することを表明します（第 7.2 条）。
