Zur Tie Public License beitragen

TPL wird von der Organisation TIE-LANG im Repository tie-lang/TPL gepflegt. Diese Seite beschreibt, wie Sie beitragen können.

Was Sie beitragen können

  • Errata und Formulierungsfehler. Tippfehler, defekte Querverweise und unklare Formulierungen im Lizenztext.
  • Übersetzungen. Eine neue Sprachfassung oder Korrekturen an einer bestehenden.
  • Auslegungshinweise. Erläuterungen, wie eine Klausel anzuwenden ist, für die FAQ.
  • Die Website. Korrekturen und Verbesserungen dieser Seite (tpl-www).

Wie sich der Lizenztext ändert

Der Lizenztext ist versioniert und eingefroren. Jede veröffentlichte Version ist unveränderlich: Sobald TPL 2.3 veröffentlicht ist, ändert sich ihr Text nicht mehr. Korrekturen und Verbesserungen fließen in die nächste Version (etwa TPL 2.4), und bereits unter einer früheren Version verbreitete Werke bleiben weiterhin dieser Version unterworfen (Section 14.3).

Das ist Absicht: Übernehmer müssen darauf vertrauen können, dass die von ihnen akzeptierten Bedingungen nicht hinter ihrem Rücken geändert werden.

Eine Änderung vorschlagen

  • Eröffnen Sie ein Issue, das das Problem beschreibt, und nennen Sie nach Möglichkeit die vorgeschlagene Formulierung. Erläutern Sie die Wirkung auf Übernehmer, nicht nur die Formulierung.
  • Für einen konkreten Entwurf eröffnen Sie einen Pull Request gegen das Drafts-Verzeichnis. Entwürfe werden vor jeder Versionsveröffentlichung geprüft.
  • Änderungen, die die rechtliche Wirkung einer Klausel verändern statt sie zu klären, gelten als neue Version und nicht als Erratum.

Eine Übersetzung beitragen

Eine Übersetzung wird als Datei neben den anderen Sprachfassungen vorgeschlagen. Bevor sie als amtliche Übersetzung bestimmt werden kann, muss sie:

  • der Struktur des englischen Textes folgen — gleiche Abschnitts- und Klauselnummerierung, damit Querverweise in jeder Sprache auflösbar sind;
  • die Ankerform der Abschnittsüberschriften beibehalten und die Hinweismuster im Appendix unverändert verwendbar lassen;
  • von einer im Zielsprachigen kompetenten Person auf rechtliche Richtigkeit geprüft werden; eine Übersetzung trägt mit der Bestimmung die Billigung des Lizenzgebers und unterliegt damit einem höheren Maßstab als eine Arbeitsfassung.

Bestimmungen werden in OFFICIAL-TRANSLATIONS.md festgehalten. Eine neue Lizenzversion erfordert eine neue Bestimmung.

Beiträge zum Text selbst

Sofern Sie nichts anderes erklären, wird alles, was Sie zur Aufnahme in den Lizenztext einreichen, zu den Bedingungen der Lizenz selbst angeboten (Section 7.1), und Sie sichern zu, dass Sie zur Einreichung berechtigt sind (Section 7.2).

Wo Sie es einreichen
