О лицензии

Лицензия

Tie Public License (TPL) — это разрешительная лицензия с открытым исходным кодом, основанная на указании авторства и опубликованная как универсальный, пригодный для многократного применения текст: любое физическое или юридическое лицо может принять её для любого вида произведений, без связи с организацией TIE-LANG и без её одобрения. Она универсальна и нейтральна в отношении области применения и написана так, чтобы ответить на вопросы, которые более новые лицензии оставляют без ответа: обучение ИИ, произведения, созданные с помощью материала, размещённые сервисы, материалы третьих лиц и защита бренда.

Кто её поддерживает

TPL публикуется и поддерживается организацией TIE-LANG — организацией, стоящей за языком программирования tie. Канонический и всегда актуальный текст лицензии — tpl.txt в репозитории tie-lang/TPL.

Политика версий

  • Текущая версия — TPL 2.3 (опубликована 2026-09-29). Для новых применений следует использовать её.
  • При каждом изменении версии репозиторий сохраняет авторитетный tpl.txt и замороженную, побайтово идентичную копию с именем по номеру версии (2.1, 2.0, …), чтобы исторические тексты оставались точно доступными.
  • Произведения, уже распространённые по более ранней версии, продолжают регулироваться той версией. Архивные тексты: 2.1, 2.0.

Об этом сайте

Этот сайт намеренно минимален — простой HTML, написанный вручную, и одна таблица стилей, в духе llvm.org: без фреймворков, без системы сборки, без клиентского JavaScript, без трекеров. Каждая страница лицензии генерируется механически из текстовых файлов репозитория TPL, поэтому прочитанное здесь побайтово соответствует каноническому тексту; при смене версии страницы перегенерируются, а не правятся вручную. Сервер согласует исходный язык по заголовку Accept-Language; переключатель в навигации ведёт напрямую к другому языку.

Применение

TPL 2.3 — стандартная лицензия репозиториев экосистемы TIE. Разрешение на её использование не требуется: форматы уведомлений см. в разделе Применение TPL, а частые вопросы — в FAQ.
