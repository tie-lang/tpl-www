Contribuer à la Tie Public License

TPL est maintenue par l'organisation TIE-LANG dans le dépôt tie-lang/TPL. Cette page décrit comment contribuer.

Ce que vous pouvez apporter

  • Errata et corrections de rédaction. Fautes de frappe, renvois brisés et formulations peu claires dans le texte de la licence.
  • Traductions. Une nouvelle version linguistique, ou des corrections à une version existante.
  • Notes d’interprétation. Des explications sur la manière dont une clause est censée s’appliquer, pour la FAQ.
  • Le site web. Corrections et améliorations de ce site (tpl-www).

Comment le texte de la licence évolue

Le texte de la licence est versionné et figé. Chaque version publiée est immuable : une fois TPL 2.3 publiée, son texte ne change plus. Les corrections et améliorations entrent dans la version suivante (par exemple TPL 2.4), et les œuvres déjà distribuées sous une version antérieure restent régies par cette version (Section 14.3).

C'est délibéré : les adoptants doivent savoir que les termes qu'ils ont acceptés ne seront pas modifiés dans leur dos.

Proposer une modification

  • Ouvrez un issue décrivant le problème et, si possible, la formulation que vous proposez. Expliquez l’effet sur les adoptants, pas seulement la formulation.
  • Pour un projet concret, ouvrez une pull request contre le répertoire des brouillons. Les brouillons sont examinés avant toute publication de version.
  • Les modifications qui altéreraient l’effet juridique d’une clause, plutôt que de l’éclaircir, sont traitées comme une nouvelle version, et non comme un erratum.

Contribuer une traduction

Une traduction est proposée sous forme de fichier, aux côtés des autres versions linguistiques. Avant de pouvoir être désignée Traduction Officielle, elle doit :

  • suivre la structure du texte anglais — la même numérotation des sections et des clauses, afin que les renvois soient résolus dans chaque langue ;
  • conserver la forme d’ancre des titres de section et laisser les modèles de mention de l’Annexe utilisables tels quels ;
  • être relue pour son exactitude juridique par une personne compétente dans la langue cible ; une traduction porte l’approbation du Concédant dès sa désignation, elle est donc tenue à un standard plus élevé qu’une version de travail.

Les désignations sont consignées dans OFFICIAL-TRANSLATIONS.md. Une nouvelle version de la licence exige une nouvelle désignation.

Contributions au texte lui-même

Sauf indication contraire de votre part, tout ce que vous soumettez pour inclusion dans le texte de la licence est offert selon les termes de la Licence elle-même (Section 7.1), et vous déclarez avoir le droit de le soumettre (Section 7.2).
