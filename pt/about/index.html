Acerca de

A licença

A Tie Public License (TPL) é uma licença de código aberto permissiva e baseada na atribuição, publicada como um texto genérico e reutilizável: qualquer pessoa singular ou coletiva pode adotá-la para qualquer tipo de obra, sem vinculação com a organização TIE-LANG nem a sua aprovação. É de uso geral e neutra quanto ao domínio de aplicação, e foi escrita para responder às questões que as licenças mais recentes deixam em silêncio: o treino de IA, as obras construídas com o material, os serviços alojados, os elementos de terceiros e a proteção da marca.

Quem a mantém

A TPL é publicada e mantida pela organização TIE-LANG, a organização por trás da linguagem de programação tie. O texto canónico e sempre atualizado da licença é o tpl.txt no repositório tie-lang/TPL.

Política de versões

  • A versão atual é a TPL 2.3 (publicada em 2026-09-29). As novas adoções devem usá-la.
  • A cada mudança de versão, o repositório conserva o tpl.txt autoritativo e uma cópia congelada e idêntica byte a byte, com o nome da versão (2.1, 2.0, …), para que os textos históricos permaneçam exatamente recuperáveis.
  • As obras já distribuídas sob uma versão anterior continuam a reger-se por essa versão. Textos arquivados: 2.1, 2.0.

Acerca deste site

Este site é deliberadamente mínimo — HTML escrito à mão e uma única folha de estilo, no espírito de llvm.org: sem frameworks, sem sistema de compilação, sem JavaScript no cliente, sem rastreadores. Cada página de licença é gerada mecanicamente a partir dos ficheiros de texto do repositório TPL, pelo que o que lê aqui é fiel byte a byte ao texto canónico; as mudanças de versão regeneram as páginas em vez de as editar à mão. O servidor negocia a língua inicial a partir do cabeçalho Accept-Language; o seletor da navegação vai diretamente para a outra língua.

Adoção

A TPL 2.3 é a licença padrão nos repositórios do ecossistema TIE. Não precisa de autorização para a usar: ver Usar a TPL para os formatos de aviso, e as perguntas frequentes para dúvidas comuns.
